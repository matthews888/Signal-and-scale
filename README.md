# Signal & Scale

Static, responsive agency website. Includes the home and careers pages.

## Deploy with GitHub and Vercel

1. Create a new GitHub repository named `signal-and-scale` and upload these three files to the repository root.
2. In Vercel, choose **Add New → Project**, import the GitHub repository, and choose **Other** as the framework preset.
3. Leave Build Command empty and use the repository root as the output directory, then deploy.
4. Future pushes to the production branch will deploy automatically.

## Before using the website for business

Replace every occurrence of `hello@signalandscale.agency` in both HTML files with an email address you control. The careers application currently opens a draft email; it does not upload resumes or save applications.

The Google Fonts stylesheet is loaded from Google's CDN. All site content and layout are contained in the two HTML files.
